# 本地聊天日记

左侧「聊天日记」或首页「写一篇聊天日记」进入。可先查看虚构示例。

1. 在「导出」选择需要的私聊和群聊，导出 JSON 或 Arkme JSON，关闭媒体和头像导出。
2. 在日记页同时导入这些 JSON。每批最多 100 个文件、40 MB、20 万条消息。
3. 选择日期、人物和关键词。日期按 Asia/Shanghai（UTC+8）划分。
4. 阅读会话摘录、跨会话人物线索和引用回复，填写「我的补记」。
5. 点击「保存日记」保存 Markdown，或「保存 JSON」保存机器可读的日记和证据。
   Windows 会打开另存为窗口，保存成功后页面显示完整路径。

该版本在本地整理事实摘录，不调用模型，不上传数据，不自动判断情绪或人物关系，
不自动推断图片含义。它按微信 ID 关联身份，不依据同名或昵称自动合并人物。
引用消息只在同一会话内通过稳定消息 ID 匹配，跨日期原文仍包含在导出证据里。

相同文件和稳定消息 ID 可以去重；缺少稳定 ID 时保留记录并提示可能重复。
不能把普通导出的 `localId` 当作全局 ID，因为它是每份导出的顺序号。
缺少有效发送者 ID 或时间的记录会跳过并显示检查提示。

导入数据和补记只保留在当前页面内存中，离开页面前请保存。
聊天日记仍由用户选择日期并保存，尚未提供聊天自动归档或模型撰写。
页面顶部是「本地工作流记录」，从前台窗口的可见区域识别文字，按时间和共同关键词归为可编辑的工作片段。
支持搜索文字证据、改名、拆分、合并，以及查看代表截图和旧截图补记。
采集规则、本地 OCR、排除应用、登录启动、暂停及归档路径参见 [工作流记录说明](./DEVICE-TIMELINE.md)。
